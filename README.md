# Smart Transit Terminal Simulation 🚌🏙️

A 3D urban bus terminal environment built using C++ and OpenGL GLUT.

## Features

- 3D city bus terminal
- Lighting and materials
- Day/Night mode
- Rain effect
- Animated vehicles
- Multiple camera views

## Technologies

- C++
- OpenGL
- GLUT

## Controls

W/S : Move camera  
A/D : Move left/right  
1-7 : Camera views  
N : Day/Night mode
